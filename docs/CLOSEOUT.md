# 知识库收尾验收（2026-11-03，北京时间）

## 交付范围

保存已有 M1/M2/P1 后端、报告和测试，补齐知识页面前端使用闭环：目录筛选、正文阅读、双向链接、原文证据跳转、人工修订、diff 审核与丢弃、正文历史回滚、发布模式切换、带出处材料预览与待审提交、知识检查提示。桌面与 390px 手机宽度均验收。

修复与加固：

- 回归启动使用当前 Python 解释器与绝对服务路径，解决虚拟环境依赖不一致导致的启动失败。
- 新增待审正文基线校验，阻止旧提案覆盖较新的正文或同名新页面。旧版没有基线的队列可丢弃，必须重新生成后发布。
- 自动编译待审应用保留页面类型及证据；已人工维护的页面拒绝自动编译队列覆盖。
- 新回答无证据时不再显示上一轮引用，问答显式展示置信档位。
- 启动优先使用项目虚拟环境，不再在每次启动时联网安装 npm 依赖。
- Git 忽略虚拟环境、缓存与临时评测日志；CI 增加前端 JavaScript 语法校验。

## 验收证据

- Python 回归：25/25 通过（含新增编译更新审核、过期提案、同名创建冲突）。
- 浏览器：上传测试资料→页面阅读→修订→审核→正文回滚→原文跳转→材料预览→提交待审→发布设置；无页面 JavaScript 错误，390px 无页面横向溢出。可复现脚本：`tests/browser_smoke.cjs`。

## 尚未验收的能力

## 使用

在项目目录执行 `PORT=8000 ./start.sh`，访问 `http://127.0.0.1:8000/#wiki`。首先去资料库上传文件即可形成知识页面。首次部署按 README 创建虚拟环境并安装依赖。先用小规模真实资料核对引用，再扩大使用。
